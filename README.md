Entry for the make.fun bounty **One Sentence for a Traveler from 1800**. The
program writes a single sentence, under 200 characters, that explains the modern
internet to someone who has just stepped out of the year 1800 — using only
pictures and words that person already knows.

The sentence:

> Picture one clerk with every address in his book and every book on his shelf:
> name a friend, however far his door, and your letter is read there at once;
> name a book and it opens on your table.

## Run it

Requires Python 3.13 (any Python 3 works).

```sh
python3 main.py
cat /output/entry.txt
```

The program is deterministic, uses no network and no randomness, and writes
exactly the sentence above (UTF-8, no trailing newline) to `/output/entry.txt`.
